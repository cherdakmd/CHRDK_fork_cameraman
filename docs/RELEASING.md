# Выпуск новой версии

1. Обновите `<version>` в `pom.xml` и проверьте ссылку на артефакт/совместимость в README.
2. Проверьте изменения локально командами `mvn clean verify` и `git diff --check`.
3. Создайте и слейте PR в `main`; CI должен успешно собрать плагин на Paper API 26.3. Плагин требует API 26.3 или новее.
4. В GitHub создайте опубликованный релиз с тегом вида `vX.Y` на коммите из `main`.
5. Workflow `Build and publish plugin release` соберёт JAR на Java 25 и прикрепит `target/cameraman-X.Y.jar` к релизу.
6. Проверьте, что JAR появился среди файлов релиза, и скачайте его для теста на Paper.

Не переиспользуйте опубликованные теги. Для исправления уже выпущенного релиза выпустите новый тег, например `v26.3.1`, обновив версию в `pom.xml`.
