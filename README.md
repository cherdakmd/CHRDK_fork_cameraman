# Кинематографичная камера для Minecraft

Плагин для сервера Minecraft Paper: назначайте игрока оператором камеры и автоматически снимайте игроков и мобов с разных ракурсов.

**Совместимость:** требуется Paper API 26.3 или новее; проверка сборки выполняется на Paper API 26.3. Плагин совместим с Purpur 26.3 и новее. Серверу потребуется Java 25; JAR собран с байткодом Java 21. Скачать последнюю сборку можно на странице [релиза v26.3.4](https://github.com/cherdakmd/CHRDK_fork_cameraman/releases/tag/v26.3.4).

## Возможности

- **Режим оператора** — назначение игрока оператором и переключение в режим наблюдателя.
- **Режим новичков** — автоматическое переключение на недавно подключившихся игроков.
- **Автоматическая ротация** — циклический выбор целей с настраиваемым интервалом.
- **Наблюдение за мобами** — выбор ближайших живых существ вместо игроков.
- **Автовыбор моба** — переключение на мобов, когда нет доступных игроков.
- **Автоматический пейзажный режим** — запуск съёмки без цели после телепортации, если режим наблюдения отключён.
- **Плавная телепортация** — кинематографичный переход между позициями камеры.
- **Сохранение настроек** — настройки и назначение оператора сохраняются после перезапуска и повторного входа.

## Команды

Все команды требуют право `cameraman.use` (по умолчанию — OP). Можно использовать `/камера` вместо `/cameraman` и русские псевдонимы подкоманд вместо английских. Аргументы, значения `true/false` и названия ракурсов остаются без изменений. Плагин проверяет типы и диапазоны аргументов до сохранения: при ошибке выводится подсказка, настройки не меняются.

| Псевдоним | Английская команда |
|---|---|
| `назначить`, `снять`, `цель`, `сбросить` | `set`, `unset`, `target`, `clear` |
| `новички`, `ротация`, `минрасстояние` | `newcomer`, `rotation`, `minrotationdistance` |
| `мобцель`, `автомобы` | `mobtarget`, `automob` |
| `плавныйтелепорт`, `наблюдение`, `наблюдениемобов` | `teleportsmooth`, `spectatemode`, `mobspectatemode` |
| `ночноезрениемобов`, `порогночногозрения`, `сообщения` | `mobnightvision`, `nightvisionthreshold`, `showmessage` |
| `дистанция`, `высота`, `скоростьорбиты`, `направлениеорбиты`, `плавность` | `distance`, `height`, `orbitspeed`, `orbitdirection`, `smoothness` |
| `длительностьпролёта`, `длительностькрана`, `минвысотакрана`, `максвысотакрана` | `flybyduration`, `craneduration`, `craneheightmin`, `craneheightmax` |
| `случайныйракурс`, `пейзаж`, `автопейзаж` | `random`, `scenic`, `autoscenic` |
| `скоростьдвижения`, `направлениедвижения` | `movespeed`, `movedirection` |
| `меню`, `профиль`, `операторы`, `траектория`, `сцена` | `menu`, `profile`, `operators`, `path`, `scene` |
| `пауза`, `дальше` | `pause`, `next` |

Примеры: `/камера назначить Steve`, `/камера ротация true 45`, `/камера пейзаж true ORBIT`. Автодополнение подсказывает подкоманды, игроков, логические значения и доступные ракурсы.

### Управление

- `/cameraman set <игрок>` — добавить независимого оператора камеры (его сессия и настройки хранятся отдельно).
- `/cameraman unset [игрок]` — снять оператора; без имени игрок снимает только себя (если он назначен), а консоль снимает первого оператора. Для офлайн-оператора можно указать UUID из списка.
- `/cameraman operators` (`/камера операторы`) — список назначенных операторов.
- `/cameraman target <игрок>` — выбрать цель.
- `/cameraman showmessage <true|false>` — включить или отключить информационные сообщения.
- `/cameraman menu` (`/камера меню`) — открыть GUI: выбрать игрока/моба, переключить режимы и ракурс, настроить дистанцию/высоту, управлять паузой и профилями. В списке профилей ЛКМ загружает профиль, ПКМ удаляет, нажатие колёсиком запускает переименование; сохранение запускается кнопкой и вводом имени в чат.
- `/cameraman pause` (`/камера пауза`) — приостановить или возобновить движение и ротацию.
- `/cameraman next` (`/камера дальше`) — вручную перейти к следующей цели; при выборе показывается ник игрока или имя моба (для моба без собственного имени — тип сущности).
- `/cameraman path <add|play|list|delete|stop|export|import> [имя] [тики-на-точку]` — записать точки траектории, воспроизвести и управлять переносом маршрутов. Точки добавляются из текущего положения оператора; для запуска нужны две точки. Экспортированные YAML лежат в `plugins/Cameraman/route-exports/`.
- `/cameraman scene <add|play|list|delete> <сцена> [траектория]` — объединить несколько траекторий в последовательный сценарий съёмки.
- `/cameraman profile <save|load|delete|list> [имя]` — сохранять и переключать профили настроек камеры (имя: латиница, цифры, дефис, подчёркивание; 1–32 символа).

### Выбор целей

- `/cameraman newcomer <true|false>` — включить режим новичков.
- `/cameraman rotation <true|false> [интервал]` — включить/отключить ротацию; интервал задаётся в секундах (по умолчанию 60).
- `/cameraman minrotationdistance <расстояние>` — минимальное расстояние для пропуска близких целей (по умолчанию 5).
- `/cameraman mobtarget <true|false>` — режим выбора мобов.
- `/cameraman automob <true|false> [задержка]` — автоматический выбор мобов, если нет игроков.
- Фильтры по умолчанию заданы в `config.yml` в секции `targetFilters` и копируются в `operatorSettings.<UUID>.targetFilters` при добавлении оператора. Последующие изменения для конкретного оператора вносите в его секцию; поддерживаются миры, исключённые игроки и права, режимы игры и невидимые игроки, минимальная/максимальная дистанция (0 отключает ограничение).
- Если цель отключается, погибает или переходит в мир, в котором запрещена фильтрами, плагин снимает её и выбирает следующую доступную.
- Меню показывает только доступных онлайн-игроков; фильтры применяются также к автоматическому выбору мобов и игроков.

### Наблюдение и камера

- `/cameraman spectatemode <true|false|RANDOM> [ракурс]` — режим наблюдения за игроками.
- `/cameraman mobspectatemode <true|false|RANDOM> [ракурс]` — режим наблюдения за мобами.
- `/cameraman teleportsmooth <true|false> [длительность]` — плавный переход к новой цели; длительность в секундах.
- Параметр `cameraSmoothing` в `config.yml` (0.01–1.0, по умолчанию 0.35) сглаживает слежение во всех движущихся ракурсах; меньше — мягче, но медленнее. Для DYNAMIC-ракурсов используется `dynamicSmoothness`.
- `cameraEasing` задаёт кривую перехода (`LINEAR`, `SMOOTHSTEP`, `EASE_IN_OUT`). Камера старается избегать твёрдых блоков; при переходе между мирами перемещение остаётся мгновенным.
- `/cameraman mobnightvision <true|false>` — ночное зрение при съёмке мобов.
- `/cameraman nightvisionthreshold <0-15>` — порог освещённости для адаптивного ночного зрения.
- `/cameraman scenic <true|false> [ракурс]` — запустить/остановить съёмку без цели от текущей позиции.
- `/cameraman autoscenic <true|false> [ракурс]` — автоматический запуск пейзажной съёмки.
- `/cameraman random <player|mob|scenic> <режим1,режим2...>` — список ракурсов для случайного выбора.

### Настройка ракурсов

- `/cameraman distance <значение|min-max>` — расстояние до цели.
- `/cameraman height <значение|min-max>` — высота камеры.
- `/cameraman orbitspeed <значение|min-max>` — скорость вращения камеры.
- `/cameraman orbitdirection <LEFT|RIGHT|RANDOM>` — направление вращения.
- `/cameraman smoothness <значение>` — плавность динамического слежения (0.01–1.0).
- `/cameraman flybyduration <секунды>` — длительность цикла пролёта.
- `/cameraman craneduration <секунды>` — длительность цикла крана.
- `/cameraman craneheightmin <значение>` и `/cameraman craneheightmax <значение>` — нижняя и верхняя высота крана.
- `/cameraman movedirection <x,y,z>` — направление движения относительно начального положения камеры; поддерживаются диапазоны.
- `/cameraman movespeed <значение|min-max>` — скорость движения.

## Ракурсы

`POV` — вид от первого лица; `BEHIND` — камера позади цели; `FRONT` — камера перед целью; `ORBIT` — вращение вокруг цели; `DYNAMIC` и варианты `DYNAMIC_BEHIND`, `DYNAMIC_FRONT`, `DYNAMIC_POV` — плавное слежение; `FLYBY` — циклический пролёт; `CRANE` — вертикальное движение; `MOVE` — движение в заданном направлении; `FIX` — неподвижная камера; `RANDOM` — случайный выбор доступного ракурса.

Если режим наблюдения отключён, камера переместится только в начальную точку ракурса; динамические эффекты требуют включённого режима наблюдения.

## Установка

1. Соберите проект и выполните тесты командой `mvn clean verify`.
2. Скопируйте JAR из `target/` в папку `plugins` сервера Paper.
3. Перезапустите сервер.

## Конфигурация

Файл `config.yml` хранит UUID оператора, параметры режимов и язык сообщений. Укажите `language: ru` или `language: en`; выбранный язык и переводы из `messages.yml` в папке данных плагина применяются после перезапуска. Файл сообщений можно редактировать, чтобы настроить формулировки.
